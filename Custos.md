# Custos

### Secure Infrastructure, Open Future.

Custos is an open-source, modular, AI-powered physical security intelligence platform designed to provide a vendor-neutral alternative to proprietary security ecosystems. Built under the **GNU Affero General Public License v3.0 or later (AGPL-3.0+)**, Custos prioritizes interoperability, privacy, resilience, transparency, and long-term sustainability.

The platform combines AI vision, identity management, zero trust security, offline networking, automation, compliance, and knowledge-driven intelligence into a unified security operating system for homes, businesses, campuses, municipalities, industrial facilities, and critical infrastructure.

---

# Vision

Custos aims to become the **open operating system for physical security infrastructure**, enabling organizations and individuals to own their data, choose their hardware, and deploy intelligent security systems without vendor lock-in.

Core principles:

- Open source
- Privacy first
- Hardware neutrality
- Modular architecture
- Local-first operation
- Interoperability
- User-owned data
- Transparent AI
- Long-term sustainability
